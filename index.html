Every item carries a source, a location, any number of categories, a description and its provenance. Museum copies add the accession number and date, conditions of loan, and thirteen fields you name yourself.

It is a catalogue, not a photo album.

Most software will let you tag a picture. Very little of it knows what an accession number is, or that a loan has conditions attached, or that where an object came from matters as much as what it is.

Virtual Archive records the things a collection actually has to answer for, and it does not make you invent a place to put them.

Plus thirteen fields you define yourself. It arrives set up with Material, Size, Time Period, Copyright, Creator, Place of Creation, Condition and Appraised Value — change any of them to suit your collection.

It writes the deed of gift.

The part nobody enjoys. Choose a donor, and Virtual Archive produces a Word document you can print and sign at the table.

Making it stamps the accession number and date onto every item included, so the paperwork and the catalogue cannot drift apart.

What comes out

  • A photograph of every item in the gift
  • A table of titles and descriptions
  • Your own logo at the head of the page
  • The gift and tax-receipt wording
  • Signature lines for the donor and for the museum

A volunteer can find things in it.

Three lists down the side — Source, Location and Categories — each opening like a drawer. Nothing to learn beyond clicking a folder.

Search reads the whole of every record, not just the description, so a name buried in a provenance note still comes back. What you find collects in a working folder, and that folder is what you then report on, export, or turn into a book.

Two things worth knowing

  • Every item is identified by a fingerprint taken from the file itself, so the same photograph cannot quietly be catalogued twice.
  • One stored copy is shared by every folder an item appears in. A photograph filed under a source, a location and five categories still takes the space of one photograph.

Nothing is ever trapped.

A catalogue is only worth keeping if you can get it back out. Any part of the collection exports to a spreadsheet of fourteen columns — source, location, categories, title, description, provenance, accession number and the rest — that opens in whatever you already use.

Whole collections, or any selection from one, save to a single file you can hand to someone else, keep as a backup, or read back in later. Reading one in can rewrite the source and location as it goes, which is what makes sharing between societies safe rather than a merge you regret.

What it needs.

Windows

Installs for your own user account. No administrator password, so no call to whoever looks after the computers.

Linux

Download, unpack, run install.sh. No Python, no internet and no administrator password.

Mac

Ready, and sent on request rather than downloaded — write and you will have it the same day, on a USB stick if you prefer. It runs on macOS 12 and later.

No internet

Nothing is sent anywhere and nothing is checked online. It works the same in a back room with no connection at all.

The Windows download is about 181 MB, the Linux one about 105 MB. A few minutes on a normal connection, longer on a slow one. If your connection makes that awkward, say so and one will be posted to you on a USB stick, ready to run with nothing to download at all.

Windows will warn you, and it is not a fault. A blue box appears reading "Windows protected your PC", because the installer is new and Windows does not recognise it yet. Click More info, then Run anyway. It installs for your own account and never asks for an administrator password.
